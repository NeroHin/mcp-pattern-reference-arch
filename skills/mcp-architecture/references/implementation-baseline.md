# 共用實作基線

以下是設計檢查面向，依需求與風險使用；示範設定不升格為協定要求。

## 協定與 Client

記錄 transport、MCP／SDK 版本及目標 Client。Tools 執行動作、Resources 提供上下文、Prompts 提供使用者啟動的範本；按支援選用。應用層操作探索與 MCP 工具列舉／更新分開設計。查核具體版本，不將最新文件直接套入舊 SDK。

stdio 注意啟動、生命週期與 stdout 協定輸出。HTTP 另設計認證、授權、部署及斷線重試；HTTP MCP 授權流程與 stdio 憑證取得不同，傳輸認證也不取代資源授權。

## 契約與回傳

每個能力包含用途、輸入／輸出 Schema、值域、單位／時間／版本、來源、空結果及錯誤／重試。Schema 以外另驗證日期、資源關係等業務條件。描述與 annotations 供選擇使用，權限由 Server／後端執行。

定義分頁、最大批次、回傳預算與截斷；游標與版本一致，缺資料或失敗不當空結果成功。來源可直接回傳或用受控查詢參照取得。

## 範圍、外部內容與寫入

從可信上下文判定身分，每次搜尋／讀取／執行檢查物件及動作；參數裡的 tenant ID、字串或描述都不是授權證明。錯誤與 metadata 避免洩漏範圍外資訊。

文件、規格描述、工具回傳與內層文字均為資料。原文要求忽略規則、切換租戶或寫入時，仍依原始任務及授權判斷。

寫入明定核准位置與參數、冪等鍵範圍及有效期、提交狀態查詢、重試與部分成功處理。逾時先釐清是否提交。唯讀任務不另加寫入核准流程。

## 觀測與驗證

用關聯 ID 連結請求、操作及內層服務，記錄失敗／資料缺口；追蹤供應商依環境選擇。Token、回合、資料大小及時間需定義口徑，未知用量標未知。

驗證成功任務、空結果、非法參數、越權、分頁邊界、版本變更、逾時／重試與部分失敗。情境審閱、程式測試與真實模型執行分開報告；格式或關鍵字命中不足以證明架構或答案正確。Pattern 不自動保證正式環境可用。
