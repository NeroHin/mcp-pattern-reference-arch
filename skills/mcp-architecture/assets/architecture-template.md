# 架構輸出欄位

這是產出指南；依規模合併欄位，回傳已填妥內容。單一決策可簡化，要求保存文件時才寫檔。

| 欄位 | 應填內容 |
| --- | --- |
| 任務與成功條件 | 代表性需求、使用者、可觀察的完成條件 |
| 事實／假設／待確認 | 來源及影響的決策；缺程式或 Client 證據時標未驗證 |
| 基線與選型 | 最小介面、Pattern 的需求依據、重要替代與代價 |
| 責任分配 | Host／Client、Server、後端、領域服務持有的規則／計算／授權／協調 |
| 介面與範圍 | 能力清單、Tools／Resources／Prompts、可信身分與物件權限位置 |
| 執行路徑 | 具體成功例子與資料不足／失敗／重試；需要時畫圖 |
| 實作與遷移 | 既有程式、可沿用部分、最小變更順序、SDK／Client／transport |
| 驗證與限制 | 已執行檢查、後續計畫、未涵蓋的正式環境條件 |

指出需要使用者決定的實際缺口；可依既有授權及明示假設繼續時，完成可完成的部分。
