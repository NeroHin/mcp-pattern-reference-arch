# 介面契約欄位

為實際公開的能力填寫，複雜介面才另附完整 JSON Schema。名稱與例子採使用者領域。

| 面向 | 應填內容 |
| --- | --- |
| 識別 | 名稱、用途、版本、呼叫條件與介面關係 |
| 輸入 | 型別、必填／預設、值域、時間／單位、最大批次及資源 ID |
| 身分／範圍 | 可信來源、每次及目標資源驗證、欄位過濾；只作選取的參數 |
| 輸出 | 結構、單位、定義／資料版本、來源與完整性／截斷 |
| 分頁／一致性 | 游標、排序、快照／版本及資料變更行為；不需分頁時說明界限 |
| 狀態／錯誤 | 空結果、資料不足、非法參數、未授權／不可見、版本衝突、逾時與部分完成 |
| 寫入／重試 | 副作用、核准或既有授權、冪等鍵及期限、提交查詢、可重試條件；唯讀標不適用 |
| 預算／觀測 | 回傳大小、時間／成本／取消、關聯 ID 與必要稽核 |
| 驗證 | 成功與拒絕案例、來源、實作與測試對照 |

以上為業務契約建議。MCP 欄位依選定版本及 SDK 使用；自訂業務 envelope 不當成協定要求。
