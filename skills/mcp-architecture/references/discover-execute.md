# Discover + Execute

## 適用與代價

操作目錄龐大或持續增加時，以固定入口找操作、讀規格並執行。價值是按需提供操作資訊，代價是搜尋品質、往返、規格版本及派送權限。少量穩定操作可直接暴露。

## 固定參數派送契約

1. 搜尋授權後的目錄，回 operation ID、用途、風險摘要及必要分頁。
2. 取得輸入／輸出規格、版本與限制。
3. 依 allowlist 解析 ID，驗證 Schema、業務語意、身分、目標及動作權限，再派送。

工具名稱依環境決定。讀到 Schema 不表示獲授權；每次派送重新檢查權限及規格有效性。處理未知方法、額外欄位、逾時及部分失敗，避免把任意 URL／函式名稱／反射直接當實作。

寫入定義預覽／確認或既有授權、冪等鍵與參數綁定、提交狀態查詢及可重試條件。逾時先查是否提交；多步驟不自動具備交易性。

## Code Mode 分支

需要生成程式跨多頁或多方法組合時，再評估執行隔離、資源／時間預算、網路出口、憑證代理、逐操作授權、取消及結果大小。無受控環境時使用固定派送或既有流程；目錄很大本身不是執行任意程式的理由。

## 本機實作與驗證

`registry.catalog` 共用 Flat／Scoped／Discover 的定義；`search_tools` 是簡易字詞搜尋，`get_tool_schema` 取規格，`call_tool` 檢查 ID 並用 Draft202012Validator 驗證參數。

外層只有三入口；沒有動態新增外層工具或生成程式執行，也未涵蓋授權、正式搜尋、寫入或規格版本協商。

測試核對派送與直接呼叫等價，拒絕未知 ID、非預期欄位及型別。擴充後另測撤權、舊規格、搜尋召回與寫入重試。
